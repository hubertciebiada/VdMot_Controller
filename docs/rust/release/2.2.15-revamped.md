## Highlights

Changes since 2.2.14. The full list is at the end of these notes.

- **A curve of up to 32 points.** `points` of `/api/valves/{n}/flow` takes 2 to 32 pairs, 2 to 16
  before. A flow equal to the flow of a point maps to exactly that point's position, so a curve
  with a point at every target the regulator sets, for example every 0.1 l/min from 0.5 to
  2.7 l/min with `[0,0]` before them (24 points), needs no interpolation for those targets.
- **A flow below the first flow of the curve is that point.** A target above 0 and below the first
  flow above 0 of the curve goes to the point of that flow and answers `clipped:true`; before, it
  lay on the line from the point without flow. With `[0,0]` and `[1070,0.5]` a target of
  0.3 l/min is 1070 pulses, no longer 642. A target of 0 still closes, and with R2 the floor
  `floorCounts` + 60 still raises a position below it.
- **Downgrade without loss.** NVS `flow` keeps the format of 2.2.14. Of a curve of more than 16
  points it holds 16, the first, the last and 14 evenly spaced by index, and the new key `flowpts`
  holds all of them; 2.2.14 and 2.2.13 ignore it and run such a curve with those 16 points. With
  no curve above 16 points `flowpts` is removed, and NVS is what 2.2.14 writes.
- **MQTT and Home Assistant** do not change. `tools/flowbench/flowcheck.py` keeps up to 32 points
  of a curve, 16 before.
- **STM32.** The code is that of 2.2.9; only the version number changes. Flashing the STM is
  optional: it keeps the versions of the two MCUs equal. Coming from 2.2.7 or older, flash it as
  2.2.13 says.

## Known limits

- **The changes did not run on hardware before this release.** They passed the host tests, the
  mutation tests of the changes and QEMU.
- **A curve of more than 16 points after a downgrade.** 2.2.14 and 2.2.13 show and run 16 of its
  points. A curve saved there replaces it; after a later 2.2.15 a valve whose curve the older
  version did not change has all of its points again.
- **The flow is calculated, not measured.** The firmware has no flow sensor. The l/min it shows
  comes from the curve at the held position.
- **NC valve inserts only.** The motion rules were derived on normally closed inserts. Nobody
  tested normally open inserts.
